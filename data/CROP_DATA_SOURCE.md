# KisanSaathi crop-history dataset

KisanSaathi can download `crop_production.csv` from the public `k0rn/India_Agri_Data` GitHub repository:

- Repository: https://github.com/k0rn/India_Agri_Data
- Direct CSV: https://raw.githubusercontent.com/k0rn/India_Agri_Data/master/agridata.csv
- Licence declared by the repository: CC0-1.0
- Upstream description: cleaned Indian agricultural statistics derived from Government of India crop-production data.
- Expected fields: state, district, crop, agricultural year, season, area in hectares, production in tonnes, and a yield field. KisanSaathi recalculates yield as production divided by area rather than trusting the source yield column.

The dataset is a community-hosted historical mirror, not a live government API and not guaranteed to contain the latest agricultural year. The code validates the CSV schema before importing it. The original file is intentionally not committed to this repository; each team member downloads it with `python -m scripts.setup_crop_data`.

## Interpretation and limitations

- Historical area and production are not a standalone planting recommendation. Today's soil, irrigation access, weather, market prices, input costs and farm-specific conditions are not represented in this dataset.
- Treat derived yields as approximate. Crop production datasets can contain crop-specific unit inconsistencies; do not compare calculated yield across unrelated crops without validating source units.
- The raw file is not generated by KisanSaathi. Keep the displayed source and historical-data disclaimer visible.
